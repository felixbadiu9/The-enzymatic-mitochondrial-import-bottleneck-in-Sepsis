This directory is comprised of the bioinformatic analysis performed in the paper "The enzymatic/mitochondrial import bottleneck in Sepsis with possible extensions to DIC : IV Glutathione and Hinokitiol as potential therapeutic candidates" and it includes : bulk signal differential expression, xCell deconvolution, and cell population shift analysis ( LMM for GSE54514 is vestigial ) . Additionally, GSE46955 was used to study the acute vs recovery phases for mGSH importers and AFG3L2  

The experiments were run on R studio Version 4.5.2. using the GEOquery, Biobase, and limma packages.
